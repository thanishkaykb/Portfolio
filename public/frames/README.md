# Life in Frames — photo folder

Drop real photographs here (college life, hackathons, projects, team moments, everyday experiences).

After adding files, open `src/data/frames.ts` and add one line per photo:

```ts
{ src: "/frames/your-photo-name.jpg", caption: "Optional caption" }
```

The 3D gallery on the website fills up automatically from that list.
Use .jpg or .png, ideally around 1200px wide. Never add stock or AI-generated images.
